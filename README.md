A Python program (standard library only, no network) that draws one English newspaper front page summing up the world news of Sunday 22 November 2026 — the COP31 climate talks collapsing in Antalya, Iran's strike on Bahrain and tankers near Hormuz, the apartment block hit in Dymer, the Democrats clinching 258 US House seats, the Russian ship damaged at Benghazi, and Nigeria's boat disaster — and writes it as a deterministic 1024x1024 PNG.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png`. Outside the grader's container, set `MAKEFUN_OUTPUT_DIR` to a writable directory instead: `MAKEFUN_OUTPUT_DIR=out python3 main.py` writes `out/entry.png`. Two runs write exactly the same bytes.
